# MoodTune 🎵

A mood-based music player built as a front-end web development learning project with AI assistance.

## Overview

MoodTune is a music player that lets users select a mood and explore a playlist suited to that mood. It features a dark, responsive interface and interactive music controls.

## Features

- Mood-based song selection
- Play, pause, next, and previous controls
- Volume and playback progress controls
- Favorite songs
- Sleep timer
- Responsive user interface

## Technologies Used

- HTML — page structure
- CSS — styling and responsive layout
- JavaScript — interactive functionality
- Local Storage — saving favorites in the browser
- GitHub Pages — website hosting

## Live Demo

https://b2karthik45.github.io/MoodTune/

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Use the music player controls to explore the application.

Some demo audio tracks may require an internet connection.
